## 2. 1·2화면 배치

- 1화면과 2화면은 전환 버튼(매거진 / 지도)으로 오간다. 매거진 탭에서는 위쪽 머리글에, 지도 탭에서는 ROUTE 패널 맨 윗줄 오른쪽에 있다(B91).
- 1화면은 매거진 한 형식이다. PC와 모바일 모두 매거진으로 연다. "종이"(B안)와 형식 전환 버튼(크게 / 종이)은 C8 F13에서 지웠다(B84).
- 2화면(지도)은 화면 전체를 지도로 채우고, 일정과 버튼은 PC 왼쪽 패널, 모바일 아래 시트에 둔다(3-3절, C8 F14).
- 전환 버튼은 미끄러지는 알약 모양(`Segmented`)이다. 매거진 탭의 넓은 화면(1280px 이상)에서는 화면 오른쪽 위 끝에 붙는다(B67).
- 위쪽 탭은 매거진 / 지도 두 개다. "리스트" 탭은 시험 후 뺐다(B78).
- 스크롤바는 웹·모바일 모두 숨긴다. 스크롤은 된다(B68).

## 3. 화면 구조 (레퍼런스 기준)

레퍼런스는 화면 구조(어떤 영역이 어떤 순서로 있는지)를 참조한다. v1.0까지는 레퍼런스의 디자인(색, 폰트, 모양, 꾸밈)을 반영하지 않았다(D5). C7부터는 작업 파일에 적은 레퍼런스의 모양도 따를 수 있고, 앱 전체의 색·글꼴·모서리는 6절 디자인 토큰을 따른다(B82).

### 3-1. 1화면 매거진

| 순서 | 영역 | 내용 |
|---|---|---|
| 1 | 맨 위 | 대표 사진이 머리글·전환 버튼 뒤부터 깔린다. 큰 여행 제목, 기간. 제목 오른쪽에 투명 날씨 패널(누르면 날씨 창, B99). 바탕색은 사진 톤 |
| 2 | GO | 제목 아래 카드 줄: 항공권·승차권·숙소·교통 패스를 종류마다 카드 하나로(여럿이면 "N건", 날짜순, 모바일은 옆으로 넘김). 누르면 창에서 예약을 하나씩 넘겨 보고 수정·삭제(B96~B98, B104) |
| 3 | DAY 1~N | 기준선(PC는 가운데 기준 좌우 번갈아, 모바일은 왼쪽 한쪽). 일차 색 점, 지역, 어두운 유리 장소 카드(누르면 펼쳐짐, 앞면에 지도 버튼, B69·B101). 저장 전 추천 카드(흐리게, B112) |
| 4 | BACK | 쓴 돈(항목별 금액, 통화별 합계·1인당, 바로 수정), 쪽지(바로 쓰기) (B71), 준비물 체크리스트(소유자만, B100) |

- 구현(C7, F10): `MagazineView`. 매거진 "크게"가 열려 있는 동안 `<html data-cover>`를 붙여 페이지 바탕색을 사진 톤으로 바꾸고, 머리글·버튼 줄을 흰 글씨로 한다(B64). 배경색은 사진 평균색을 검정 쪽으로 65% 섞는다(B61).
- 대표 이미지가 없으면 목적지 색의 산 능선 SVG(B62). 장소 사진이 없으면 일차 색 그라데이션(B70). 일차 색은 지도와 같다(B63).
- 장소 사진(C8, F22): DAY 장소 카드에 관광지는 Wikimedia Commons, 그 밖은 Google Places 사진(3-5절). 카드 앞면 오른쪽 위에 ⓘ 하나(Google 사진은 옆에 작은 "Google Maps")를 두고, ⓘ를 누르면 사진 크게 보기 창에 출처 전체를 보인다(`PhotoInfo`, B142).
- **C9에서 바뀜**: DAY BY DAY는 하루의 시작·끝을 교통 거점 또는 숙소로 두고 중간의 교통·숙소는 넣지 않는다(F26 #59). 붙여넣기 추출 미리보기가 DAY BY DAY 자리에 사진과 함께 보인다(F28 #61). 예약 링크는 "예약 링크 열기" 버튼만(F26). BACK 쓴 돈은 합계와 정산 버튼(F27 #60, 3-4절). 배경은 대표 사진 전체(F21 #41, 2단계).
- 제목 아래 정보 칩(기간·일정·함께·기록)은 두지 않는다(B65). 날씨는 Open-Meteo(B74), 준비물은 브라우저에만 저장한다(B76).
- 구현(C8, F16): GO 카드는 `TicketStrip`의 종류별 묶음이다(`src/lib/trips/go-info.ts`가 항공권·승차권·교통 패스를 이름으로 나눔, B104). 창은 카드 아래 좌우 화살표(키보드 ← →)로 예약을 넘기고, 닫기·수정·삭제는 아이콘 버튼이다(B97). 창은 화면 폭·높이로 키우는 비율을 정해 스크롤 없이 들어오게 한다(B102). 수정 중 바깥을 누르면 고친 것이 있을 때만 묻는다(B105).
- 예약 줄(C8, F20): 소유자에게만 GO 창·장소 카드·지도 핀 세부에 예약번호(`K7••••XM`, "보기")와 예약 링크(도메인만, "주소 보기"·"열기", 비밀 링크는 "열기"만)가 보인다(`BookingInfo`, B126).
- 추천 카드(C8, F18): 추천이 들어오면 그 DAY가 펼쳐지고 머리에 "추천 N"이 보인다. 카드는 "넣기"(저장)·"고치기"(저장 전 값만)·"빼기"(추천만 지움). 보기 전용에는 보이지 않는다(B112).
- 장소 카드는 화면에 들어올 때 차례로 떠오르고, 움직임 줄이기 설정이면 움직이지 않는다.

### 3-3. 2화면 지도

| 위치 | 내용 |
|---|---|
| 바탕 | 화면 전체(맨 위부터 맨 아래까지)에 구글맵, 일차별 색 번호 핀과 동선. 머리글은 그리지 않는다(B90) |
| PC 왼쪽 패널 / 모바일 아래 시트 | ROUTE 제목 줄(오른쪽에 매거진/지도 전환), 일차 고르기, 일차별 장소 목록(번호, 이름, 종류·지역), 장소 사이 거리 |
| PC 패널 아래 | 고른 장소의 세부(이름·종류·시각·주소·메모·비용·링크·예약 줄)와 이전/다음 |
| 오른쪽 위 | 작은 步 로고. 누르면 이메일·여행 목록·공유·로그아웃 메뉴(B92) |
| 오른쪽 가운데 | 지도 확대/축소 버튼(B93) |

- 레퍼런스의 동선은 직선이지만, 실제 구현은 실제 경로를 따른 동선으로 그린다.
- 구현(v0.7): 아래 일차 고르기·장소 카드·경로 규칙은 v0.7부터 그대로이고, 배치는 C8 F14에서 바꿨다(아래 C8 구현).
  - 일차 탭: "전체"와 DAY 1~N. 고른 일차의 핀과 경로는 진하게, 다른 일차는 흐리게 남는다(B89).
  - 장소 카드: 고른 장소의 이름·종류·시각·주소와 이전/다음 버튼. 핀이나 목록을 누르면 그 장소를 고르고 지도가 옮겨 간다.
  - 선 모양 셋(C8 F15, B134): 실제 경로는 실선, 경로를 못 찾아 직선으로 이은 구간은 짧은 대시, 비행기·교통 구간은 둥근 점선. 패널 구간 표시는 "비행기"·"교통"(직선거리).
  - "전체"에서 동선이 겹치면 앞 일차를 굵게 아래에, 뒤 일차를 가늘게 위에 그린다. 장소를 고르면 그 일차 동선이 맨 위에 진하게 보인다(B23). 좌표가 없는 장소 수는 목록 아래에 따로 알려 준다.
- 꾸미기(C7, F11): 큰 "ROUTE" 제목, 일차별 큰 "DAY n" 제목, 둥근 장소 버튼(고른 장소는 일차 색 테두리), 구간 거리는 알약, 일차 고르기는 미끄러지는 알약 버튼(많으면 옆으로 넘김), 장소 카드는 큰 이름과 둥근 이전/다음 버튼(B79).
- 구현(C8, F14, `MapView`·`RouteMap`·`MapMenu`)
  - 지도 섹션은 `fixed inset-0`으로 화면 전체를 덮고, 지도를 옮길 때 패널에 가린 곳을 빼고 핀이 보이게 여백을 둔다.
  - PC: 패널 오른쪽 가장자리의 탭(‹)으로 접으면 왼쪽 끝에 다시 펴기 탭(›)만 남고 지도가 화면 전체를 쓴다. 접힘은 저장하지 않는다(B94).
  - 모바일: 시트 맨 위 손잡이(누르는 곳 128×44px)를 누르거나 밀어 펼치고 접는다. 접으면 손잡이만 남는다. 이전/다음 카드는 없고, 고른 장소의 세부는 목록 줄 아래에 펼친다. 핀을 누르면 시트를 펼치고 그 줄로 스크롤한다(B95). 편집할 수 있는 사람은 펼친 목록 끝에 "+ 입력" 버튼 자리를 비운다(B87).
  - 들어올 때 `?item=`이 없으면 현재 시각에 가장 가까운 일정의 핀을 고른다(`src/lib/map/nearest.ts`, B88).
- 구현(C8, F15, 동선 규칙)
  - 하루 동선의 시작은 그날 도착하는 교통의 도착 거점(없으면 전날 숙소), 끝은 그날 밤 숙소(떠나는 날이면 출발 거점). 교통 항목은 "출발 거점 → 도착 거점" 두 점으로 들어간다(`src/lib/map/route-plan.ts`, B132).
  - 지도에는 번호 핀과 공항 거점의 작은 ✈ 표시만 있다(누르는 기능 없음). 기차역·터미널 거점과 전날 숙소는 표시 없이 선의 점으로만 쓴다. 패널 목록과 번호는 그대로다(B133).
  - 비행기 구간이 다른 나라까지 이어지면 지도 범위는 그날 장소만 기준으로 맞추고 점선은 화면 밖으로 이어진다(B130).
  - PC에서 패널을 접은 채 핀을 누르면 패널이 펼쳐지고 세부가 보인다(B135).
- 지도 안에 "지도 / 리스트" 전환을 두는 안은 시험 후 뺐다(B78).
- **C9에서 바뀜 (F25 #58, F23 #56)**: 동선·✈ 표시·구간 거리·이동수단과 패널 세부(PC 장소 카드, 모바일 목록 줄 아래 세부)를 없애고 일차별 색 핀만 둔다(R-06 b안). 핀을 누르면 핀 위 팝업(이름·일정 시간·주소·메모, 메모 없으면 숨김)과 구글맵 버튼. 지도 탭의 곰발바닥 버튼 삭제. 핀으로 올릴 일정은 F26의 하루 일정 규칙을 따른다. 오른쪽 위 로고 메뉴는 2단계 F23에서 통일 상단바로 바뀐다.

## 4. 이동 흐름

1. 로그인 → 여행 목록 → (새 여행 만들기 또는 선택) → 여행 상세 1화면
   - PC·모바일 모두 매거진으로 열린다(B84).
2. 1화면 → [입력 버튼] → 입력창
   - 붙여넣기 → 미리보기 → 저장 → 1화면·지도·비용에 반영. 일차·시각을 원문에서 못 정한 항목은 매거진 추천 카드 → "넣기"로 저장(C8 F18)
   - 말 걸기("둘째 날 일정 짜 줘") → 대화창의 제안 미리보기 → "저장", 또는 저장된 일정 고치기·지우기 카드 → "반영"·"삭제"(C8 F19)
   - 직접 입력 → 저장 → 1화면·지도·비용에 반영
3. 1화면에서 장소 카드의 지도 버튼 누르기 → 2화면(지도)으로 넘어가 해당 핀으로 이동
4. 여행 상세 → [공유](지도 탭은 오른쪽 위 로고 메뉴 안) → 공유 창 → 링크 복사 → 닫기
5. 공유받는 사람: 공유 링크 열기 → 구글 로그인 → 해당 여행 상세(보기 전용)
   - 이후에는 자기 여행 목록에서 "공유받음"으로 다시 연다.
   - 입력·수정·삭제·공유 버튼은 보이지 않는다.
6. 어느 화면에서든 로그아웃(지도 탭은 로고 메뉴 안) → 로그인 화면

### 5-1. (지움) 형식 고르기

> v0.4의 형식 고르기는 C8 F13에서 지웠다(B84). 브라우저에 남은 `stepmap:schedule-format` 값은 읽지도 지우지도 않는다(B85).

### 5-2. 입력창 (v0.4)

- 오른쪽 아래 입력 버튼으로 연다. PC는 오른쪽 옆 창, 모바일은 아래에서 올라오는 창이다. C8(F17)부터 버튼은 곰발바닥 모양의 둥근 버튼이고 읽기 이름은 "입력창 열기"/"입력창 닫기"다(B108).
- 닫기: 같은 버튼(PC), 창의 ✕ 버튼, Esc 키. 닫으면 포커스가 입력 버튼으로 돌아간다.
- 보내기는 v0.5(직접 입력), v0.6(붙여넣기 추출)에서 연결한다.
- 장소 사진은 출처가 정해질 때까지 빈 자리로 둔다(대표 이미지는 3-5절, `open-questions.md`).
- C7(F10)부터 항목 수정 창은 어두운 유리 패널(`edit-sheet.tsx`, `form-styles.ts`)이다. 입력창은 C8(F17)부터 한지 톤 토큰으로 칠한 밝은 패널이다(B109).
- 창 제목은 "일정 넣기", 아래 탭은 "붙여넣기"(왼쪽, 처음 열 때)와 "직접 입력"(오른쪽). 탭마다 안내·저장 알림·쓰던 내용을 따로 갖고, 탭을 오가거나 창을 닫아도 남는다(B106).
- 직접 입력은 종류마다 필요한 칸만 받는다(B107). 교통은 편명·출발지·도착지를 따로 받아 이름 "KE123 ICN → KIX"로 합쳐 저장하고, 수정할 때 다시 나눈다(B110). 그 종류에 없는 칸은 원래 값을 숨은 칸으로 보내 지워지지 않게 한다.
- 예약 칸(C8, F20): 교통·숙소·식당에 예약번호·예약 링크·링크 공개 범위(자동 / 나만 보기 / 나만 보기·주소 숨김 / 공유한 사람도 보기), 관광지에 예약번호. 메모에는 없다(B121, B124). 예약 칸이 있는 폼만 `booking=1`을 보낸다(B128). 저장 금지 정보가 있으면 저장하지 않고 안내한다(B127).
- 선택 칸(통화, 일차)의 펼친 목록은 흰 바탕·검은 글씨다(B103).

### 5-3. 붙여넣기와 미리보기 (v0.6)

- 붙여넣기 탭에서 원문(최대 5,000자)을 보내면 "추출 중" 말풍선이 뜨고, 끝나면 미리보기가 같은 창 안에 열린다. C8(F19)부터 이 탭은 대화창이다(아래).
- 미리보기는 항목 카드 목록이다. 카드마다 "넣기" 체크(기본 켬)와 직접 입력과 같은 칸(종류, 일차, 시각, 이름, 주소, 메모, 링크, 비용·통화)이 있다.
- "고른 항목 저장"을 누르면 체크한 항목만 저장하고 1화면에 반영한다. 하나라도 입력값이 틀리면 저장하지 않고 몇 번째 항목이 틀렸는지 알려 준다.
- "취소"를 누르면 미리보기를 닫는다. 같은 원문을 다시 추출하는 버튼은 두지 않지만, 같은 원문도 다시 보낼 수 있다(B17, C8 F18).
- 입력칸 아래 안내는 F20 문구다: 링크·예약번호는 AI에 보내지 않고, 저장 금지 정보는 가린다(B18, B125).
- 어느 항목에도 붙지 않은 예약번호는 미리보기 위에 "어느 항목인지 못 정한 예약번호"로 보인다(B125).
- 추천(C8, F18): 원문에 일차·시각이 다 있는 항목만 미리보기로 간다. 일차나 시각을 AI 추천이나 "일정이 가장 적은 날"로 정한 항목은 미리보기 없이 매거진 해당 DAY의 추천 카드로 가고, 입력창에 "추천 N개를 DAY BY DAY에 띄웠습니다"가 보인다(B16, B112). 메모 종류는 추천 카드로 보내지 않고 바로 저장한다.
- 대화창(C8, F19)
  - 입력칸 하나에 원문을 붙여넣거나 말을 건다. 보내면 `routeMessage`가 추출/대화를 고르고(애매하면 대화), 결과마다 "대화로 다시 보내기 / 붙여넣기로 뽑기"를 둔다(B113).
  - 보낸 말, 도우미 답장, 추출 미리보기, 일정 제안 미리보기(AI 추천 표시, Places에서 못 찾으면 "찾지 못함"·넣기 끔, 영업시간·폐업 안내), 고치기·지우기 카드(바뀌기 전→후 또는 지울 일정, "반영"·"삭제"·"취소"), 다음 말 추천 칩이 위에서 아래로 쌓인다(B116, B117, B120).
  - 제안은 "저장"을, 고치기·지우기는 카드 버튼을 눌러야만 반영된다. 새 제안이 오면 앞의 열린 카드는 닫는다.
  - 대화 기억은 `chat-store.ts`(여행별 localStorage `stepmap:chat:<tripId>`, 최근 40개). "대화 지우기"로 지운다. 추출 미리보기를 저장하거나 닫으면 그 안의 예약 정보는 기록에서 지운다(B119).

### 5-4. 공유와 보기 전용 (v0.9)

- 소유자: 여행 상세 위쪽 "공유" 버튼(지도 탭은 오른쪽 위 로고 메뉴 안, B92) → 공유 창(링크, 복사 버튼, "링크를 아는 구글 사용자는 누구나 볼 수 있고 취소할 수 없다"는 안내).
- 공유받은 사람: "공유받음 · 보기 전용" 표시. 입력 버튼, 공유 버튼, 항목 수정·삭제, 여행 이름 수정·삭제가 보이지 않는다. 지도와 쓴 돈은 그대로 본다. C8부터 추천 카드·준비물·예약 줄도 보이지 않는다(B100, B112, B126). 예약 정보는 서버가 아예 보내지 않는다.
- 목록: 공유받은 여행은 내 여행과 같은 목록에 섞고 "공유받음" 표시를 붙인다.
- 틀린 공유 링크: "공유 링크가 올바르지 않습니다" 안내와 목록으로 가는 링크.
- 뽑은 항목이 없으면 "찾은 항목이 없습니다"라고 알려 준다.

- `white`는 한지 흰색 `#f8f1e3`, `zinc-50`~`zinc-950`은 베이지 회색으로 바꿔 두었다. 기존 화면의 `bg-white`·`zinc-*`도 톤이 맞는다(B40, B46).
- 매거진 "크게"가 열려 있는 동안은 `--background`가 사진 톤으로 바뀐다(B64).
- 다크 모드는 시스템 설정을 따른다. 정식 지원 여부는 `open-questions.md`.

### 6-3. 모서리·그림자·상호작용 (B41, B43)

## 7. 브랜드 이미지 (C9 킥오프)

팀이 정한 이미지 파일이다. Next.js `public/` 아래에 있어 코드에서는 `/brand/...` 주소로 바로 쓴다. 파일을 바꿀 때는 같은 경로에 덮어 써서 코드를 고치지 않게 한다.

| 파일 | 내용 | 크기 | 쓰는 곳 |
|---|---|---|---|
| `public/brand/logo.png` | 로고: 발자국 + 빨간 핀 + "stepmap" 글자 | 227×97 PNG, 베이지 바탕 | 머리글·지도 메뉴의 로고(지금의 `步` 대신, F21 #41), 상단바 왼쪽 위(F23 #56), 새 여행 만들기 버튼(F21), 사진을 못 불러온 교통 거점·숙소 카드의 대체 이미지(F26 #59) |
| `public/brand/sky-background.webp` | 하늘·구름·지구와 세계 명소 일러스트 | 1672×941 WebP | 첫 화면(`/login`) 배경(F21), 여행 목록 뒷배경에 반투명을 넣어 사용(F21, 안건 2 "하늘 계열 반투명") |

- `<img>`로 쓴다(Next.js 이미지 최적화를 쓰지 않음, B49).
- 로고 파일은 캡처본이라 베이지 바탕이 들어 있다. 투명 바탕 원본이 생기면 같은 경로로 바꾼다. 대체 이미지(F26)도 나중에 다른 사진으로 바꿀 수 있다(C9 킥오프 "사진과 로고는 미정, 일단 로고").
- 파비콘(`src/app/favicon.ico`)은 F21에서 로고에 맞춰 바꾼다.
