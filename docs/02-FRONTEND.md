# 02-FRONTEND

화면 구조와 컴포넌트, 모바일 배치를 정하는 문서입니다.

> 작성: AI · 갱신: 사이클마다

## 1. 화면 목록

| 화면 | 내용 | 관련 R |
|---|---|---|
| 로그인 | 구글 로그인 버튼 | R-01 |
| 여행 목록 | 내 여행과 공유받은 여행을 한 목록에 섞어 보여 주고, 공유받은 여행은 표시로 구분한다. 새 여행 만들기, 이름 수정, 삭제 | R-02, R-08 |
| 여행 상세 – 1화면(일정) | 일차별 항목, 고치기·지우기, 비용 영역 | R-04, R-05, R-07, R-09 |
| 여행 상세 – 2화면(지도) | 일차별 색 실제 경로 동선 또는 핀 | R-06, R-07 |
| 입력창 | 버튼으로 여닫는 채팅 모양 창. 붙여넣기 또는 직접 입력 | R-03, R-04, R-05 |
| 추출 결과 미리보기 | 확인·수정 후 저장 | R-04 |
| 공유 창 | 공유 링크 만들기·복사. 소유자에게만 보인다. | R-08 |
| 공유 링크 진입 | 로그인하지 않았으면 로그인으로 보내고, 로그인 후 해당 여행으로 이동한다. | R-08 |

## 2. 1·2화면 배치

- 1화면과 2화면은 여행 상세 위쪽의 전환 버튼(매거진 / 지도)으로 오간다.
- 1화면은 두 형식이 있다. PC와 모바일 모두 사용자가 원하는 형식을 골라 쓸 수 있다.

| 형식 | 기본값 |
|---|---|
| A안 "크게" | PC |
| B안 "종이" | 모바일 |

- 2화면(지도)은 PC와 모바일이 같다.

## 3. 화면 구조 (레퍼런스 기준)

레퍼런스는 화면 구조(어떤 영역이 어떤 순서로 있는지)만 참조한다. 레퍼런스의 디자인(색, 폰트, 모양, 꾸밈)은 반영하지 않는다.

### 3-1. 1화면 A안 "크게"

| 순서 | 영역 | 내용 |
|---|---|---|
| 1 | 맨 위 | 여행 제목, 기간, 기록 수, 대표 이미지 |
| 2 | GO | 출발과 머물 곳. 항공(출발→도착, 편명, 날짜·시각), 숙소(체크인·체크아웃) |
| 3 | DAY 1~N | 일차별 장소(사진, 시각, 이름, 부가 설명) |
| 4 | BACK | 쓴 돈(항목별 금액, 통화별 합계), 쪽지(메모) |

### 3-2. 1화면 B안 "종이"

| 순서 | 영역 | 내용 |
|---|---|---|
| 1 | 위쪽 | 여행 제목, 기간, 기록 수 |
| 2 | 교통·숙소 요약 | 항공(출발→도착, 편명, 날짜·시각), 숙소(기간) |
| 3 | DAY 1~N | 시각, 장소 이름, 부가 설명, 사진 |
| 4 | 아래쪽 | 쓴 돈(항목별 금액, 통화별 합계), 쪽지(메모) |

### 3-3. 2화면 지도

| 위치 | 내용 |
|---|---|
| 왼쪽 | 일차별 장소 목록(번호, 이름, 종류·지역), 장소 사이 거리 |
| 오른쪽 | 구글맵 위에 일차별 색 번호 핀과 동선 |
| 아래쪽 | 일차 탭(day1~dayN)과 장소 카드(이전/다음 넘기기) |

- 레퍼런스의 동선은 직선이지만, 실제 구현은 실제 경로를 따른 동선으로 그린다.

### 3-4. 비용 위치

- 1화면 아래쪽 "쓴 돈" 영역에 둔다.
- 이 영역에 통화별 합계와 통화별 1인당 금액을 표시한다.

### 3-5. 사진·이미지

- 대표 이미지와 장소 사진을 어디서 가져올지는 미정이다. 기록만 해 둔다. → `open-questions.md`

## 4. 이동 흐름

1. 로그인 → 여행 목록 → (새 여행 만들기 또는 선택) → 여행 상세 1화면
   - PC는 A안, 모바일은 B안으로 열린다. 형식은 언제든 바꿀 수 있다.
2. 1화면 → [입력 버튼] → 입력창
   - 붙여넣기 → 미리보기 → 저장 → 1화면·지도·비용에 반영
   - 직접 입력 → 저장 → 1화면·지도·비용에 반영
3. 1화면에서 장소 누르기 → 2화면(지도)으로 넘어가 해당 핀으로 이동
4. 여행 상세 → [공유] → 공유 창 → 링크 복사 → 닫기
5. 공유받는 사람: 공유 링크 열기 → 구글 로그인 → 해당 여행 상세(보기 전용)
   - 이후에는 자기 여행 목록에서 "공유받음"으로 다시 연다.
   - 입력·수정·삭제·공유 버튼은 보이지 않는다.
6. 어느 화면에서든 로그아웃 → 로그인 화면
