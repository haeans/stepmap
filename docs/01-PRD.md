# 01-PRD

무엇을 왜 만드는지, 요구사항(R-번호)·범위·제외 범위·완료 기준을 정하는 최상위 문서입니다.

> 작성: AI 초안, 사람 확정 · 갱신: 범위가 바뀔 때만 (3인 합의) · 기준: 계획서 v1.0 (2026-10-30)

## 1. 개요

- **주제**: 흩어진 여행 정보를 붙여넣기만 하면 한 장의 여행 계획과 지도 위 동선이 완성된다. 떠나기 전에는 계획이 되고, 다녀온 뒤에는 추억으로 남는다.
- **배경·문제**: 여행 정보가 여기저기 흩어져 있어 정리하기 어렵고 불편하다.
  - 흩어진 정보: 티켓(항공·열차 등), 예약 메일(숙소 등), 메모, 링크, 지도, 동선, 비용
- **목표**: 여행 일정을 깔끔하게 정리해 여행 중에 실제로 쓰고, 다녀온 뒤에는 추억으로 남길 수 있게 한다.
- **대상 사용자**: 여행을 계획하는 사람 누구나 (국내·해외 여행 모두)

### 용어

| 용어 | 뜻 |
|---|---|
| 동선 | 구글맵 위에서 일정 항목을 시간순으로 이어 그린 선이다. 직선이 아니라 실제 경로를 따라 그린다. |
| 1화면 | 여행 상세의 일정 화면(매거진)이다. v1.0~C7은 A안(크게)과 B안(종이) 두 형식이었고, C8에서 종이를 삭제해 한 형식이 된다(F13). |
| 교통 거점 | 공항, 기차역, 버스터미널처럼 여행지에 들고 나는 곳이다. 동선의 시작과 끝이 된다(C8, F15). |
| 2화면 | 여행 상세의 지도 화면이다. PC와 모바일이 같다. |

## 2. 요구사항 (R-번호)

|---|---|---|---|---|

| R-03 | 버튼으로 여는 입력창 | R-02 | C2 | F02 |
| R-04 | 붙여넣기 → 자동 추출 | R-03, R-05 | C3 | F03 |

### R-01 구글 로그인

- **동작**: 로그인·로그아웃. 로그인해야 사용할 수 있다.
- **완료 기준**: 자기 여행만 보이고, 자기 여행만 고칠 수 있다.

### R-02 여행 목록

- **동작**: 여행을 만들고, 목록에서 골라 열고, 이름을 고치거나 지운다. 공유받은 여행도 같은 목록에 섞어서 보여 주되, 공유받은 여행임을 구분해 표시한다.
- **완료 기준**: 여행을 2개 이상 만들고 서로 오가며 열 수 있다. 여행 이름을 고치고, 여행을 지울 수 있다.

### R-03 버튼으로 여는 입력창

- **동작**: 평소에는 닫혀 있고, 버튼을 누르면 채팅 모양의 입력창이 열린다.
- **완료 기준**: 버튼으로 열고 닫힌다.

### R-04 붙여넣기 → 자동 추출

- **동작**: 붙여넣기 → AI 추출 → 미리보기에서 확인·수정 → 저장
- **완료 기준**: 예시 원문이 미리보기를 거쳐 1화면에 들어간다.
- **검수**: 예시 원문 준비와 검수는 AI가 한다.
- **의존 이유**: R-05와 같은 항목 구조·저장 경로를 쓴다.
- **AI 공급자**: 제공받은 Claude API 키를 먼저 쓰고, 쓸 수 없으면 Gemini 키로 바꾼다. 공급자를 바꿔도 다른 기능에 영향이 없도록 추출 부분을 한곳에 모아 둔다.

### R-05 직접 입력·수정

- **동작**: 입력창에서 직접 입력하고, 들어간 항목을 고치거나 지운다.
- **완료 기준**: 모든 종류(5종)의 항목을 넣고, 고치고, 지울 수 있다.

### R-06 지도

- **동작**: a안을 먼저 시도한다.
  - **a안**: 같은 날의 항목을 시간순으로 이어 실제 경로를 따라 동선을 그리고, 일차별로 색을 다르게 한다.
  - **b안**: 일차별 색 핀. a안 구현이 불가능하면 b안으로 간다.
  - 국내 여행도 a안 대상에 포함한다.
- **완료 기준**: a안 또는 b안이 동작한다.
- **의존 이유**: 좌표가 있는 항목이 필요하다.

### R-07 1화면 → 2화면 연결

- **동작**: 일정에서 장소를 누르면 2화면(지도)으로 넘어가 해당 핀으로 이동한다.
- **완료 기준**: 누르면 지도가 그 핀으로 이동한다.

### R-08 공유

- **동작**: 소유자가 공유 링크를 만들어 전달한다. 링크로 들어온 사람은 자기 구글 계정으로 로그인한 뒤 그 여행을 보기 전용으로 받는다. 받은 여행은 그 사람의 여행 목록에 "공유받음"으로 표시된다.
- **완료 기준**: 초대받은 사람은 볼 수만 있고 고칠 수 없다.
- **제한**: v1.0은 구글 계정만 지원한다. 공유 취소는 확장 단계에서 다룬다.

### R-09 비용 합계·정산

- **동작**: 항목에 적힌 비용(금액·통화)을 통화별로 따로 합계 낸다. 환율 계산은 하지 않는다. 여행에 적힌 동행 인원 수로 나눠 통화별 "1인당 금액"을 보여 준다.
- **완료 기준**: 비용이 있는 항목을 넣으면 통화별 합계와 통화별 1인당 금액이 맞게 표시되고, 항목을 고치거나 지우면 결과도 바로 바뀐다.
- **의존 이유**: 항목의 비용 칸을 쓴다.

### 공통 처리

- 장소 이름이나 주소를 좌표로 바꾸는 단계(지오코딩)가 R-04·R-05의 저장 과정에 들어간다.
- 붙여넣는 원문은 티켓·예약 메일·메모·링크 텍스트다.

## 3. v1.0 완성 기준

R-01~R-09의 완료 기준을 모두 통과하고, 3명이 함께 확인해 합의하면 완성이다.

- AI 일정 도우미(F18·F19)는 구글맵 할당량을 제약으로 두지 않는다. 호출이 늘어 할당량이 모자라면 haeans가 할당량과 예산 알림을 조정한다(B30).
- AI가 추천한 장소는 저장할 때 지금처럼 좌표를 찾고, 영업시간·폐업 여부는 틀릴 수 있다고 화면에 안내한다.
- 예약번호는 AI에 보내지 않는다(B18). 보내기 전에 앱에서 골라내 따로 저장한다.
- 담당자는 이 표를 보고 정해 `docs/features/README.md` 3절에 적는다.

## 5. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 지도 a안 실패 | 구현이 불가능하면 b안(일차별 색 핀)으로 간다. C4의 첫 작업으로 판정한다. |
| 국내 경로 제한: 한국에서는 구글의 도보·자동차 경로가 제한될 수 있다 [가정] | 국내도 a안으로 시도한다. 이동 수단을 바꿔(예: 대중교통) 시도하고, 그래도 안 되는 구간의 처리는 C4 계획 단계에서 정한다. |
| 제공받은 Claude 키를 쓸 수 없음 | Gemini로 바꾼다. 추출 부분을 한곳에 모아 두어 다른 기능은 그대로 둔다. |
| 구글맵 비용 발생 | 일일 할당량 제한, 예산 알림, 키 사용 도메인 제한 |
| 추출 정확도 (날짜·시각·장소·금액·통화 오인식) | 미리보기에서 수정하는 단계를 필수로 둔다. 비용은 미리보기에서 확인하게 한다. |
| 지오코딩 오류 (같은 이름의 다른 장소) | 여행 목적지를 함께 넘겨 검색한다. 미리보기에서 주소를 확인한다. |
| 비용 통화가 섞임 | 통화별로 따로 합계를 낸다. |
| 공유 링크 유출: 링크를 아는 구글 사용자는 누구나 볼 수 있다. v1.0에는 공유 취소가 없다. | 링크 식별값을 추측하기 어렵게 만들고, 소유자에게 이 점을 안내한다. |
| RLS 우회 | Drizzle은 정의만 맡고 데이터 처리는 Supabase 클라이언트로 한다. 검수 때 보기 전용 계정으로 직접 수정을 시도해 본다. |
| API 키 노출 | 키는 서버 쪽과 Vercel 환경 변수에만 둔다. 저장소에 올리지 않는다. |
| 붙여넣은 원문 속 개인정보 | 원문은 저장하지 않는다. 예시 원문은 개인정보를 가린 것으로 쓴다. |
| 무료 DB 일시 정지 | 시연 전에 미리 접속해 깨워 둔다. |
| AI 일정 도우미의 추천이 틀림 (없는 장소, 바뀐 영업시간) (C8) | 저장 전 미리보기에서 사용자가 허락한 것만 저장한다. 좌표를 못 찾은 장소는 "위치 없음"으로 보인다. 확인 후 저장하라고 안내한다. |
| AI 일정 도우미로 구글맵·Gemini 호출이 늘어남 (C8) | 구글맵 할당량은 제약으로 두지 않고 haeans가 사용량을 보고 조정한다. 예산 알림은 유지한다. Gemini는 무료 등급 한도 안에서 쓴다. |
| 예약번호·예약 링크 노출 (C8) | 원래 값은 소유자만 읽을 수 있는 곳에 두고(RLS), 화면에는 가려서 보여 준다. AI에는 보내지 않는다. |
| Places 사진 요금 (C8, F22) | 장소는 항목을 저장할 때 한 번만 찾는다. 사진은 브라우저 캐시로 다시 받지 않게 하고, haeans가 할당량과 예산 알림을 둔다(B30). |
