## 2. 개발 순서

| 순서 | 내용 | 비고 |
|---|---|---|
| 0) 기반 | GitHub 저장소, Vercel·Supabase·Google Cloud 설정, 키·할당량 설정, 빈 화면 배포 | 월요일 전 |
| 1) C1 | 계정·목록 | 이후 모든 기능의 권한 기반 |
| 2) C2 | 입력창·직접 입력 | 항목 구조(비용 칸 포함)와 저장 경로 확정 |
| 3) C3 | 자동 추출 | C2의 저장 경로를 재사용하고, 미리보기를 추가 |
| 4) C4 | 지도·연결 | a안(실제 경로)을 시도하고, 구현이 불가능하면 b안. 지도 a안 판정은 11/2 안에 한다. |
| 5) C5 | 비용 합계·정산 | C2의 비용 칸을 모아 통화별 합계와 1인당 금액 계산 |
| 6) C6 | 공유 | 완성된 화면 전체에 보기 전용을 씌움 |
| 7) 최종 검수 | 9개 완료 기준과 회귀 목록을 한꺼번에 확인 | 11/4 (수), 3인 합의로 완성 선언 |
