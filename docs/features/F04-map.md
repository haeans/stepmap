# F04 지도·연결

지도(2화면)와 1화면 → 2화면 연결 기능의 명세입니다.

> 사이클: C4 · R-번호: R-06, R-07 · 작성: AI · 갱신: 해당 사이클
> 상태는 `features/README.md`에서 관리한다.

## 1. 범위

- R-06 지도
- R-07 1화면 → 2화면 연결
- 지도 a안 판정은 이 사이클의 첫 작업으로 한다.

## 2. R-06 지도

- **동작**: a안을 먼저 시도한다.
  - **a안**: 같은 날의 항목을 시간순으로 이어 실제 경로를 따라 동선을 그리고, 일차별로 색을 다르게 한다.
  - **b안**: 일차별 색 핀. a안 구현이 불가능하면 b안으로 간다.
  - 국내 여행도 a안 대상에 포함한다.
- **완료 기준**: a안 또는 b안이 동작한다.
- **의존**: R-05 (좌표가 있는 항목)
- **정렬 기준**: 일차 → 시각 → 순서

## 3. R-07 1화면 → 2화면 연결

- **동작**: 일정에서 장소를 누르면 2화면(지도)으로 넘어가 해당 핀으로 이동한다.
- **완료 기준**: 누르면 지도가 그 핀으로 이동한다.
- **의존**: R-06

## 4. 관련 화면 (`02-FRONTEND.md`)

- 1화면과 2화면은 여행 상세 위쪽의 전환 버튼(매거진 / 지도)으로 오간다.
- 2화면은 PC와 모바일이 같다.

| 위치 | 내용 |
|---|---|
| 왼쪽 | 일차별 장소 목록(번호, 이름, 종류·지역), 장소 사이 거리 |
| 오른쪽 | 구글맵 위에 일차별 색 번호 핀과 동선 |
| 아래쪽 | 일차 탭(day1~dayN)과 장소 카드(이전/다음 넘기기) |

- 레퍼런스의 동선은 직선이지만, 실제 구현은 실제 경로를 따른 동선으로 그린다.

## 5. 리스크

- **국내 경로 제한**: 한국에서는 구글의 도보·자동차 경로가 제한될 수 있다 [가정].
  - 국내도 a안으로 시도한다. 이동 수단을 바꿔(예: 대중교통) 시도한다.
  - 그래도 안 되는 구간의 처리는 C4 계획 단계에서 정한다. → `open-questions.md`
- **구글맵 비용**: 일일 할당량 제한, 예산 알림, 키 사용 도메인 제한

## 6. 관련 결정 (`decisions.md`)

- D5: 2화면(지도)은 PC와 모바일이 같다. 동선은 실제 경로를 따른다.
- D7: 지도 a안 구현이 불가능하면 b안으로 간다.
- Q3: 국내 여행도 포함한다. 지도는 국내도 a안으로 시도한다.
- Q11: 동선은 구글맵 위에서 시간순으로 이은 실제 경로다 (직선 아님).

## 7. 층별 설계

### 7-1. a안 판정 (v0.7 첫 작업)

Routes API(`computeRoutes`)로 확인했다. **a안으로 간다** (B20).

| 지역 | 자동차 | 도보 | 대중교통 |
|---|---|---|---|
| 홍콩 | 경로 나옴(경유지 포함) | 경로 나옴 | 경로 나옴(두 지점만) |
| 서울 | 빈 결과 | 빈 결과 | 경로 나옴(두 지점만) |

- 국내는 자동차·도보 경로가 나오지 않아 구간마다 대중교통으로 찾는다. 대중교통도 없으면 그 구간만 직선 점선으로 잇는다.

### 7-2. R-06 지도, R-07 1화면 → 2화면 연결 (v0.7)

| 층 | 파일 | 내용 |
|---|---|---|
| 화면 | `src/app/trips/[tripId]/page.tsx` | `?view=map`이면 지도 화면. 일차별 경로를 서버에서 구해 넘긴다. `item`이 있으면 그 장소를 고른 상태로 연다. |
| 화면 | `.../_components/map-view.tsx` | 2화면. 왼쪽 장소 목록, 오른쪽 지도, 아래쪽 일차 탭과 장소 카드 |
| 화면 | `.../_components/route-map.tsx` | 구글맵. 일차별 색 번호 핀, 경로 선, 고른 핀으로 이동 |
| 화면 | `.../_components/item-card.tsx` | 좌표가 있는 장소 이름을 누르면 `?view=map&item={id}`로 간다(R-07). |
| 서버 | `src/lib/map/routes.ts` | 일차별 경로 구하기(Routes API)와 캐시 |
| 공통 | `src/lib/map/places.ts` | 지도에 올릴 장소 고르기, 일차별 번호, 일차 색, 직선거리 |

- DB 변경 없음.
- 결정: B20~B23 (`decisions.md`)
