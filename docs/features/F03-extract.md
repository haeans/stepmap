# F03 자동 추출

붙여넣은 원문을 AI가 일정 항목으로 추출하는 기능의 명세입니다.

> 사이클: C3 · R-번호: R-04 · 작성: AI · 갱신: 해당 사이클
> 상태는 `features/README.md`에서 관리한다.

## 1. 범위

- R-04 붙여넣기 → 자동 추출
- C2(F02)의 저장 경로를 재사용하고, 미리보기를 추가한다.

## 2. R-04 붙여넣기 → 자동 추출

- **동작**: 붙여넣기 → AI 추출 → 미리보기에서 확인·수정 → 저장
- **완료 기준**: 예시 원문이 미리보기를 거쳐 1화면에 들어간다.
- **검수**: 예시 원문 준비와 검수는 AI가 한다.
- **의존**: R-03, R-05 (R-05와 같은 항목 구조·저장 경로를 쓴다)
- **AI 공급자**: 제공받은 Claude API 키를 먼저 쓰고, 쓸 수 없으면 Gemini 키로 바꾼다. 공급자를 바꿔도 다른 기능에 영향이 없도록 추출 부분을 한곳에 모아 둔다.

## 3. 입력과 처리

- 붙여넣는 원문은 티켓·예약 메일·메모·링크 텍스트다.
- 장소 이름이나 주소를 좌표로 바꾸는 단계(지오코딩)가 저장 과정에 들어간다. 여행 목적지를 함께 넘겨 검색한다.
- 붙여넣은 원문은 저장하지 않고 추출 결과만 저장한다. 예약번호 같은 개인정보가 남는 것을 줄이기 위해서다.
- "다시 추출하기"는 하지 않는다.
- 링크 주소만 붙여넣었을 때 그 페이지 내용을 읽어 오는 기능은 확장 단계에서 다룬다.

## 4. 관련 화면 (`02-FRONTEND.md`)

- 입력창: 버튼으로 여닫는 채팅 모양 창. 붙여넣기 또는 직접 입력
- 추출 결과 미리보기: 확인·수정 후 저장
- 흐름: 1화면 → [입력 버튼] → 입력창 → 붙여넣기 → 미리보기 → 저장 → 1화면·지도·비용에 반영

## 5. 리스크

| 리스크 | 대응 |
|---|---|
| 제공받은 Claude 키를 쓸 수 없음 | Gemini로 바꾼다. 추출 부분을 한곳에 모아 두어 다른 기능은 그대로 둔다. |
| 추출 정확도 (날짜·시각·장소·금액·통화 오인식) | 미리보기에서 수정하는 단계를 필수로 둔다. 비용은 미리보기에서 확인하게 한다. |
| 지오코딩 오류 (같은 이름의 다른 장소) | 여행 목적지를 함께 넘겨 검색한다. 미리보기에서 주소를 확인한다. |
| 붙여넣은 원문 속 개인정보 | 원문은 저장하지 않는다. 예시 원문은 개인정보를 가린 것으로 쓴다. |
| Gemini 무료 등급은 입력 내용이 서비스 개선에 쓰일 수 있다 [가정] | 예시 원문은 개인정보를 가린 것으로만 쓴다. |
| 사용량 초과 | 원문 길이 제한, 사용량 확인, 키는 서버 쪽에만 둔다. |

## 6. 관련 결정 (`decisions.md`)

- D1: 검수용 예시 원문 준비와 ④ 검수는 AI가 한다.
- E1: 제공받은 Claude API 키를 쓰고, 쓸 수 없으면 Gemini 키를 쓴다.
- 원문: 붙여넣은 원문은 저장하지 않고 추출 결과만 저장한다.
- Q10: 링크 내용 읽어 오기는 확장 단계에서 다룬다. 구현이 불가능하다고 판단되면 AI가 팀에 요청한다.

## 7. 층별 설계

### 7-1. R-04 붙여넣기 → 자동 추출 (v0.6)

| 층 | 파일 | 내용 |
|---|---|---|
| 화면 | `.../_components/input-panel.tsx` | "붙여넣기" 탭. 원문을 보내면 추출 중 표시 후 미리보기를 연다. |
| 화면 | `.../_components/extract-preview.tsx` | 미리보기. 항목마다 "넣기" 체크와 수정 칸. 저장하면 고른 항목만 넣는다. |
| 화면 | `.../_components/item-fields.tsx` | 항목 입력 칸 묶음. 직접 입력 폼과 미리보기가 같이 쓴다. |
| 서버 | `src/app/actions/extract.ts` | `extractItems`(원문 → 미리보기 항목), `saveExtractedItems`(고른 항목 저장) |
| 공통 | `src/lib/extract/gemini.ts` | Gemini 호출. 공급자를 바꿀 때는 이 파일만 바꾼다. |
| 공통 | `src/lib/extract/mask.ts` | 보내기 전에 이메일·전화번호·카드 번호 같은 값을 가린다. |
| 공통 | `src/lib/extract/prompt.ts` | 지시문과 여행 정보(목적지, 기간) 문장 |
| 공통 | `src/lib/extract/normalize.ts` | AI 결과를 항목 입력값 모양으로 고르고 다듬는다(일차 범위, 시각 형식, 통화). |
| 공통 | `src/lib/items/validation.ts` | 직접 입력과 같은 검사. 미리보기 저장도 이 검사를 거친다. |

- DB 변경 없음. 저장할 때 `source`를 `ai`로 둔다.
- 저장 경로는 R-05와 같다: 입력값 검사 → 좌표 찾기 → `items`에 넣기(RLS 적용).
- 원문은 서버 액션 안에서 AI에 넘기고 버린다. DB와 로그에 남기지 않는다.
- 결정: B14~B19 (`decisions.md`)
