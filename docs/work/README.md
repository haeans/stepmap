# 작업 파일

4단계(수정·확장)에서 작업마다 하나씩 만드는 파일의 안내와 양식입니다.

> 작성: AI · 갱신: 양식이 바뀔 때 (① 킥오프)
> 규칙: `docs/integration.md` 4절

## 규칙

- 브랜치 하나에 작업 파일 하나. 이름은 브랜치 이름에서 `/`를 `-`로 바꾼 것이다. 예: `hyunw/f07-photo` → `docs/work/hyunw-f07-photo.md`
- 작업 브랜치에서는 이 파일과 코드만 고친다. 공통 문서(`docs/` 바로 아래 문서, `features/`, `README.md`, `CLAUDE.md`)는 고치지 않는다.
- 결정은 임시 번호(`[파일 이름] 결정 1`)로 적는다. B-번호는 ④ 공통 문서 최신화 때 haeans가 붙인다.
- ④에서 공통 문서로 옮긴 뒤에는 맨 위에 "반영 완료"를 적고 파일은 남겨 둔다.
