  - DB 변경 (없음)

| [hyunw0000-f07-design-tone] 결정 2 | 화면 | 새 화면 코드는 `bg-background`·`text-foreground`·`bg-surface`·`text-muted`·`border-line`·`bg-accent`를 쓴다. 기존 `zinc-*`는 `globals.css`에서 따뜻한 회색으로 바꿔 두었으므로 그대로 써도 톤이 맞는다. |
| [hyunw0000-f07-design-tone] 결정 3 | 화면 | 모서리: sm 0.5rem, md 0.75rem, lg 1rem, xl 1.25rem, 2xl 1.5rem. 그림자는 옅고 넓게. |

| [hyunw0000-f07-design-tone] 결정 5 | 화면 | 키보드 포커스는 포인트 색 2px 테두리로 통일. 창(dialog) 뒤는 흐리게. |
| [hyunw0000-f07-design-tone] 결정 6 | 화면 | 머리글은 스크롤해도 위에 붙고 뒤가 흐리게 비친다. 모바일에서는 이메일을 숨긴다. |
| [hyunw0000-f07-design-tone] 결정 8 | 화면 | 로고는 낙관(도장) 모양의 인주색 사각형에 `步`(걸음). 종이 결은 이미지 파일 없이 SVG 무늬로 그린다. 흰색 토큰도 한지 흰색(`#f8f1e3`)으로 바꿔 `bg-white`를 쓰는 입력창·종이 형식도 톤이 맞는다. |

- (해결) F08·F10·F11이 먼저 머지되어 이 브랜치를 최신 `main` 위로 옮기며 맞췄다(2026-11-03). `globals.css`는 F07 토큰 + F10 스크롤바 숨김. `app-header.tsx`는 className을 넘기면 F10의 펼친 머리글(바깥 글자색), 안 넘기면 F07의 위에 붙는 머리글, 로고는 둘 다 `步` 낙관. `trip-row.tsx`는 F08 대표 이미지 위에 F07 카드 모양(그림자·hover).
