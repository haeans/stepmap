## 4. 결정 (임시 번호)

| 번호 | 영역 | 결정 |
|---|---|---|
| [hyunw0000-f21-design-finish] 결정 1 | 화면 | 하늘 배경은 `<img>`를 화면에 고정(`fixed inset-0 -z-10`)해 깐다. `background-attachment: fixed`는 모바일 사파리에서 동작하지 않아 쓰지 않는다. 그림은 아래 기준(`object-bottom`)으로 맞춰 지구·명소가 잘리지 않게 한다 |
| [hyunw0000-f21-design-finish] 결정 2 | 화면 | 목록의 "하늘 계열 반투명"은 하늘 그림 위에 `sky-50` 60~75% 막(다크 모드는 `slate-950` 75~85%)으로 한다. 한지 바탕(B46) 대신 이 막이 목록 화면의 바탕이 된다 |
| [hyunw0000-f21-design-finish] 결정 3 | 화면 | 매거진 배경은 대표 사진 전체를 화면에 고정한다(B61·B64 고침). 평균색(B61)은 버리지 않고 사진 위 막의 색으로 쓴다. 막 진하기는 스크롤로 정한다: 맨 위 25%, 제목 영역 높이만큼 내려가면 80%. 위쪽 28%는 머리글 흰 글씨를 위해 검정 45% → 0 그라데이션을 그대로 둔다. `<html data-cover>`와 `--background` 바꾸기(B64)는 그대로 둔다 |
| [hyunw0000-f21-design-finish] 결정 4 | 화면 | 새 발자국 버튼은 로고 그림(`logo-mark.png`, 높이 32px) 오른쪽 아래에 인주색(`--accent`) "+" 동그라미를 붙이고 글자 "새 발자국"을 둔다. 하늘 배경 위라 검정 알약 대신 밝은 유리 알약(`bg-surface/90`, 글자 #603820, F23 로고 글자색과 같음) |
| [hyunw0000-f21-design-finish] 결정 5 | 브랜드 | 파비콘은 Next.js 파일 규칙 `src/app/icon.png`로 두고 `favicon.ico`는 지운다. 원본 `logo-mark.png`가 67×60이라 256×256으로 늘리면 조금 흐리다. 투명 바탕 원본이 생기면 같은 파일을 바꾼다 |
| [hyunw0000-f21-design-finish] 결정 6 | 화면 | 여행 목록의 상단바는 띠(B44 흐린 띠, F23 결정 2) 없이 하늘 배경 위에 로고·프로필만 둔다(`AppHeader floating`, 매거진과 같음). 그래서 목록에서는 스크롤하면 상단바도 같이 올라간다(위에 붙지 않음). 공유 링크 오류 화면은 한지색 띠 그대로 |
