# F10 매거진 탭 개편

> 담당: hyunw0000(김현우) · 이슈: #22 · 브랜치: `hyunw0000/f10-magazine` · 킥오프: 2026-11-02
> 상태: 작업 중

## 1. 범위

- PRD 4절 C7 F10: 매거진 탭에서 대표 사진이 배경으로 들어가고, 사진 톤에 맞는 배경색이 페이지를 채운다. PC는 기준선 좌우 번갈아, 모바일은 기준선 기준 한쪽 정렬.
- 1화면 A안 "크게"를 매거진 모양으로 바꾼다. 영역 순서(맨 위 → GO → DAY 1~N → BACK, 02-FRONTEND 3-1)는 지키되 GO는 맨 위 예약 카드 줄로 올린다.
- 담당자 지시(2026-11-02)로 함께 한다: 사진이 머리글·전환 버튼까지 덮기, 움직이는 전환 버튼과 카드, 제목 아래 정보 칩 대신 교통·숙소 예약 카드(누르면 팝업), 넓은 화면에서 전환 버튼을 오른쪽 위 끝으로, 스크롤바 숨김.
- 하지 않는 것: B안 "종이"(F11), 대표 이미지 저장·업로드(F08), 장소 사진(출처 미정), DB 변경.

### 레퍼런스

- 작업자가 준 `f10.png`와 고해상도판 `일본의 안개 낀 풍경 여행 가이드.png`: 사진이 메뉴 줄까지 덮는 첫 화면, 큰 제목, 사진 카드 줄, 가운데 기준선에 일정이 좌우로 번갈아 붙는 "ABOUT THE TOUR", 어두운 반투명 카드 4개의 "WHAT'S INCLUDED".
- 미리보기용 대표 사진: `홍콩 빅토리아항의 황혼 야경.png`, `아침 안개 속 교토풍 계곡 풍경.png` (F08 전 로컬 확인용).
- 이미지 파일은 저장소에 올리지 않았다.

## 2. 완료 기준

- [ ] 매거진 "크게"에서 대표 사진이 페이지 맨 위(머리글·전환 버튼 뒤)부터 제목 영역까지 깔리고, 그 위 글자·버튼이 흰색으로 읽힌다.
- [ ] 페이지 바탕색이 사진 톤으로 바뀌어 끝까지 채운다. "종이"·지도로 옮기면 원래 바탕으로 돌아온다. 대표 이미지가 없으면 목적지로 정한 임시 그림과 그 색을 쓴다.
- [ ] 제목 아래에 교통·숙소 예약 카드가 가로로 놓이고(모바일은 옆으로 넘김), 누르면 팝업으로 종류·일차·날짜·시각·편명/주소·비용·메모·예약 링크가 보인다. 팝업에서 수정·삭제가 된다(보기 전용은 숨김).
- [ ] PC(768px 이상)에서 DAY가 가운데 기준선을 두고 좌우 번갈아, 모바일에서 왼쪽 기준선을 따라 한쪽으로 놓인다.
- [ ] 장소 카드는 어두운 유리 카드이고, 화면에 들어올 때 차례로 떠오르며 마우스를 올리면 살짝 뜬다. 움직임 줄이기 설정이면 움직이지 않는다.
- [ ] 매거진/지도, 크게/종이 버튼은 고른 쪽으로 알약이 미끄러진다. 넓은 화면(1280px 이상)에서는 화면 오른쪽 위 끝에 붙는다.
- [ ] 웹·모바일 모두 스크롤바가 보이지 않고 스크롤은 된다. 가로 스크롤이 생기지 않는다.
- [ ] 장소 이름 → 지도 이동(R-07), 쓴 돈 합계·1인당(R-09), 보기 전용(R-08)이 그대로 동작한다.

## 6. 질문

- F08 머지 후 대표 이미지 주소를 어디서 넘길지(`trips` 칸 이름)는 F08 결과를 보고 연결한다. 연결은 F10 PR에서 할지 F08 이후 작은 PR에서 할지 정해야 한다.
