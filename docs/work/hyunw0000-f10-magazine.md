# F10 매거진 탭 개편

> 담당: hyunw0000(김현우) · 이슈: #22 · 브랜치: `hyunw0000/f10-magazine` · 킥오프: 2026-11-02
> 상태: 작업 중

## 1. 범위

- PRD 4절 C7 F10: 매거진 탭에서 대표 사진이 배경으로 들어가고, 사진 톤에 맞는 배경색이 페이지를 채운다. PC는 기준선 좌우 번갈아, 모바일은 기준선 기준 한쪽 정렬.
- 1화면 A안 "크게"를 매거진 모양으로 바꾼다. 영역 순서(맨 위 → GO → DAY 1~N → BACK, 02-FRONTEND 3-1)는 그대로다.
- 하지 않는 것: B안 "종이"(그대로 둠), 대표 이미지 저장·업로드(F08), 장소 사진(출처 미정), 공통 디자인·글꼴(F07), DB 변경.

### 레퍼런스

- 작업자가 준 `f10.png`(어두운 산 풍경 사진 위 큰 제목, 사진 카드 줄, 가운데 세로 기준선에 일정이 좌우로 번갈아 붙는 "ABOUT THE TOUR", 반투명 카드 4개의 "WHAT'S INCLUDED").
- 화면 구조와 분위기(사진 배경, 사진 톤의 어두운 배경, 기준선 좌우 배치, 반투명 카드)를 참고했다. 이미지 파일은 저장소에 올리지 않았다.

## 2. 완료 기준

- [ ] 매거진 탭(A안 "크게") 맨 위에 대표 사진이 배경으로 깔리고 그 위에 여행 제목·목적지·기간·일수·인원·기록 수가 보인다.
- [ ] 페이지 배경색이 사진 톤에 맞춰 바뀌고 페이지 아래 끝까지 채운다. 대표 이미지가 없으면 목적지로 정한 임시 그림과 그 색을 쓴다.
- [ ] PC(768px 이상)에서 DAY가 가운데 기준선을 두고 좌우 번갈아 놓인다.
- [ ] 모바일에서 DAY가 왼쪽 기준선을 따라 한쪽으로 정렬된다.
- [ ] 항목 수정·삭제, 장소 이름 → 지도 이동(R-07), 쓴 돈 합계·1인당(R-09), 보기 전용(R-08)이 그대로 동작한다.
- [ ] 가로 스크롤이 생기지 않는다.
