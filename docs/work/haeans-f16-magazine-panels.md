## 1. 범위

- PRD 4절 C8 F16
  - 같은 종류의 패널은 하나로 묶고, 팝업에서 나눠 볼 수 있게 한다. 패널은 날짜순.
  - 날씨는 패널에서 빼서 여행 제목 오른쪽 투명 패널로 두고, 누르면 원래 날씨 창을 연다.
  - 준비물은 패널에서 빼서 BACK으로 옮긴다. 체크리스트는 유지한다(세부는 구현해 보고 정함).
  - 일정 카드를 누르면 세부가 열리는 기능은 유지하고, 세부를 보는 버튼 위에 지도로 가는 버튼을 둔다.
- F13(종이 삭제) 머지 후 최신 `main`에서 시작했다.
- 하지 않는 것
  - 표지와 아래 색 이어지게(디자인, 2단계 F21)
  - 예약번호 마스킹(F20). 숙소 창의 "메모 · 예약번호 ••••••" 표시는 지금 그대로 둔다.
  - DB 변경, 공통 문서 수정

## 2. 완료 기준

- [x] GO 줄에 종류마다 카드가 하나씩만 있다(항공권·숙소·교통 패스). 같은 종류가 여럿이면 "N건"으로 묶인다.
- [x] 카드를 누르면 창 위의 탭으로 예약을 하나씩 나눠 보고, 각 예약을 수정·삭제할 수 있다. 탭과 카드는 날짜순이다.
- [x] 날씨는 GO 줄에 없고, 여행 제목 오른쪽 투명 패널에 있다. 누르면 원래 날씨 창이 열린다.
- [x] 준비물은 GO 줄에 없고 BACK에 체크리스트로 있다. 공유받은 사람에게는 보이지 않는다.
- [x] 장소 카드 앞면의 펼침 버튼 바로 위에 지도 버튼이 있고, 누르면 지도 탭에서 그 핀이 골라진다. 카드를 누르면 세부가 펼쳐지는 기능은 그대로다.
- [x] `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` 통과

## 4. 결정 (임시 번호)

| 번호 | 영역 | 결정 |
|---|---|---|
| [haeans-f16-magazine-panels] 결정 1 | 화면 | "같은 탭은 한 패널로"는 GO 줄의 항공권·숙소·교통 패스를 종류마다 카드 하나로 묶는 것으로 본다. 카드 제목은 첫 예약(여럿이면 "외 N편/곳/건"), 아래 줄은 첫 날짜–마지막 날짜. B65·B73의 "항목마다 카드"를 고친다. |
| [haeans-f16-magazine-panels] 결정 2 | 화면 | 묶은 카드의 창은 위에 탭(날짜 · 편명 또는 이름)을 두고 한 번에 예약 하나를 보여 준다. 예약이 하나면 탭이 없다. 수정·삭제는 지금처럼 창 아래에서 한다. 지워서 줄어들면 마지막 탭을 보여 준다. |
| [haeans-f16-magazine-panels] 결정 3 | 화면 | 날짜순: 카드 안의 예약은 일차 → 시각 → 순서(`compareItems`), 카드끼리는 각 카드의 가장 이른 예약 순서. 예전의 고정 순서(항공권 → 숙소 → 패스)는 쓰지 않는다. |
| [haeans-f16-magazine-panels] 결정 4 | 화면 | 날씨는 여행 제목 오른쪽의 투명 패널(아이콘, 최고 기온, 날씨, 날짜 · 예보/작년 기준). 좁은 화면에서는 제목 아래로 내려간다. 누르면 원래의 날씨 창(B74). |
| [haeans-f16-magazine-panels] 결정 5 | 화면 | 준비물은 BACK의 세 번째 칸(쓴 돈, 쪽지 다음)에 체크리스트 그대로 둔다. 창이 아니라 바로 체크한다. 저장은 브라우저(B76 그대로), 공유받은 사람에게는 보이지 않는다. 모양(흰 카드)은 2단계 디자인(F21)에서 정한다. |
| [haeans-f16-magazine-panels] 결정 6 | 화면 | 장소 카드의 "세부를 보는 버튼"은 앞면 오른쪽 아래 펼침 버튼으로 보고, 그 바로 위에 지도 버튼(핀 아이콘, `?view=map&item=`)을 둔다. 좌표가 없는 장소에는 없다. 서랍 안의 "지도에서 보기"는 지운다. B69를 고친다. |
