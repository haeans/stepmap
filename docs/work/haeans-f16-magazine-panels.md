## 1. 범위

- PRD 4절 C8 F16
  - 같은 종류의 패널은 하나로 묶고, 팝업에서 나눠 볼 수 있게 한다. 패널은 날짜순.
  - 날씨는 패널에서 빼서 여행 제목 오른쪽 투명 패널로 두고, 누르면 원래 날씨 창을 연다.
  - 준비물은 패널에서 빼서 BACK으로 옮긴다. 체크리스트는 유지한다(세부는 구현해 보고 정함).
  - 일정 카드를 누르면 세부가 열리는 기능은 유지하고, 세부를 보는 버튼 위에 지도로 가는 버튼을 둔다.

## 2. 완료 기준

- [x] GO 줄에 종류마다 카드가 하나씩만 있다(항공권·승차권·숙소·교통 패스). 같은 종류가 여럿이면 "N건"으로 묶인다.
- [x] 카드를 누르면 카드 아래 좌우 화살표로 예약을 하나씩 넘겨 보고, 각 예약을 수정·삭제할 수 있다. 넘기는 순서와 카드는 날짜순이다.
- [x] 날씨는 GO 줄에 없고, 여행 제목 오른쪽 투명 패널에 있다. 누르면 원래 날씨 창이 열린다.

- [x] 장소 카드 앞면의 펼침 버튼 바로 위에 지도 버튼이 있고, 누르면 지도 탭에서 그 핀이 골라진다. 카드를 누르면 세부가 펼쳐지는 기능은 그대로다.
- [x] `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` 통과

## 4. 결정 (임시 번호)

| 번호 | 영역 | 결정 |

| [haeans-f16-magazine-panels] 결정 1 | 화면 | "같은 탭은 한 패널로"는 GO 줄의 항공권·숙소·교통 패스를 종류마다 카드 하나로 묶는 것으로 본다. 카드 제목은 첫 예약(여럿이면 "외 N편/곳/건"), 아래 줄은 첫 날짜–마지막 날짜. B65·B73의 "항목마다 카드"를 고친다. |
| [haeans-f16-magazine-panels] 결정 2 | 화면 | 묶은 카드의 창은 한 번에 예약 하나를 보여 주고, 카드 바로 아래 줄의 좌우 화살표(키보드 ← →도)로 넘긴다. 화살표 사이에 점(몇 번째)과 지금 예약 이름(날짜 · 편명 또는 이름). 예약이 하나면 줄이 없다. 지워서 줄어들면 마지막 것을 보여 준다. 닫기·수정·삭제는 아이콘 버튼(✕·연필·휴지통, 마우스를 올리면 글자)으로, 웹(md 이상)은 카드 오른쪽에 세로(닫기 → 수정 → 삭제), 좁은 화면은 카드 위 오른쪽에 가로(수정 · 삭제 · 닫기). 날씨 창도 같은 닫기 버튼. (검수 반영: 처음에는 창 위 탭과 창 아래 글자 버튼, 그다음 웹에서 오른쪽 세로 글자 버튼이었음) |
| [haeans-f16-magazine-panels] 결정 3 | 화면 | 날짜순: 카드 안의 예약은 일차 → 시각 → 순서(`compareItems`), 카드끼리는 각 카드의 가장 이른 예약 순서. 예전의 고정 순서(항공권 → 숙소 → 패스)는 쓰지 않는다. |
| [haeans-f16-magazine-panels] 결정 4 | 화면 | 날씨는 여행 제목 오른쪽의 투명 패널(아이콘, 최고 기온, 날씨, 날짜 · 예보/작년 기준). 좁은 화면(sm 미만)에서도 제목 오른쪽 위에 두고 아이콘·기온만 작게 보인다. 누르면 원래의 날씨 창(B74). (검수 반영: 처음에는 모바일에서 제목 아래로 내려갔음) |
| [haeans-f16-magazine-panels] 결정 5 | 화면 | 준비물은 BACK의 세 번째 칸(쓴 돈, 쪽지 다음). 기본 목록 없이 비어 있고, 제목 옆 "＋ 준비물 추가"로 하나씩 더하면 한 줄씩 생긴다. 하나라도 있어야 패널이 보인다. 패널은 BACK의 다른 칸과 같은 반투명 모양이고, 머리(진행률 원 + 개수 + D-day)를 누르면 서랍처럼 접혀 원과 개수만 남는다. 저장은 브라우저(B76 그대로), 공유받은 사람에게는 보이지 않는다. (검수 반영: 처음에는 기본 6개가 든 흰 카드였음) |
| [haeans-f16-magazine-panels] 결정 6 | 화면 | 장소 카드의 "세부를 보는 버튼"은 앞면 오른쪽 아래 펼침 버튼으로 보고, 그 바로 위에 지도 버튼(핀 아이콘, `?view=map&item=`)을 둔다. 서랍 안의 "지도에서 보기"도 그대로 둔다. 좌표가 없는 장소에는 둘 다 없다. B69를 고친다. (검수 반영: 처음에는 서랍 안 버튼을 지웠음) |
| [haeans-f16-magazine-panels] 결정 7 | 화면 | GO 창은 스크롤 없이 화면에 다 들어오게 한다. 키우는 비율(zoom)을 화면 폭과 **높이**로 함께 정한다: 폭 48rem·높이 38rem 이상 1.25배, 폭 64rem·높이 44rem 이상 1.4배, 그보다 낮으면 키우지 않음. 숙소 창은 사진 높이를 줄이고 "지금 보는 숙소 · 주소" 줄을 지웠다(위 주소와 겹침, "다음 숙소 · 이름"만 남김). 아주 낮은 화면에서 넘칠 때만 창 안 스크롤. (검수 반영: 숙소 창 위아래 잘림 → 스크롤 → 스크롤 없이) |
| [haeans-f16-magazine-panels] 결정 9 | 화면 | 비행기가 아닌 교통 항목을 둘로 나눈다. 이름에 패스·N일권·일일권·자유이용·프리·free·무제한·정기권·교통카드 같은 말이 있으면 **교통 패스**(기간 안에 자유롭게 타는 표), 아니면 **승차권**(정해진 구간·시각이 있는 기차·버스·배 표). 승차권 카드는 TICKET 모양(출발 → 도착, 날짜, 출발 시각, 타는 곳(주소), 요금, 메모)이고, 이름의 화살표(→, ->, ~, >)로 출발·도착을 나눈다(앞의 말은 열차·버스 이름). 화살표가 없으면 이름만 크게. GO 카드는 항공권·승차권·숙소·교통 패스 넷이 된다. B65·B73의 "비행기가 아닌 교통 = 교통 패스"를 고친다. 추출이 교통을 나눠 주는 것은 F18에서(아래 질문). (검수 반영: KTX·버스표도 교통 패스로 나왔음) |
| [haeans-f16-magazine-panels] 결정 8 | 화면 | 입력·수정 칸의 선택 목록(통화, 일차)은 펼친 목록만 흰 바탕·검은 글씨로 고정한다(`form-styles.ts`의 `FIELD`에 한 줄). F17이 입력창을 밝게 바꿀 때 같이 다시 본다. (검수 반영: 통화 선택 글씨가 안 보임) |
| [haeans-f16-magazine-panels] 결정 10 | 화면 | GO 창에서 수정 중 나가기: 한 칸도 안 고쳤으면 바깥 누르기·Esc·"← 돌아가기"로 바로 나간다. 고쳤으면 "수정한 내용을 저장하지 않고 닫을까요?"(`window.confirm`, 삭제 확인과 같은 방식)를 묻고, 취소하면 수정창에 남는다. 창을 열 때마다 몸통을 새로 그려 다시 열면 늘 원래 카드가 보인다. DAY 장소 카드·추천 카드의 수정 창(처음부터 수정 전용 창)은 그대로 둔다. (검수 반영: 수정 중 바깥을 눌러 나갔다 다시 열면 수정창이 그대로 보였음) |
