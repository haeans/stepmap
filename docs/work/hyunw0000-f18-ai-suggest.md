# F18 AI 일정 도우미 1: 일차·시각 없는 일정 추천

## 1. 범위

PRD 4절 C8 F18 ("v1.0 이후 후보"의 "AI 일정 도우미"). F17(입력창 개선, PR #45 머지) 위에 쌓는다.

1. **추천값 받기**: 붙여넣기 추출 때 원문에 일차·시각이 없는 항목은 AI가 추천 일차·시각과 짧은 이유를 같이 준다. 호출은 지금처럼 한 번이다(추출과 추천을 한 번에).
2. **이미 있는 일정을 맥락으로**: 추천할 때 빈 날·같은 지역을 보도록 이미 저장된 일정의 종류·일차·시각·이름·주소를 함께 보낸다(메모·링크·비용은 보내지 않음).
3. **"모르면 DAY 1" 없애기**: 원문에도 AI 추천에도 일차가 없으면 일정이 가장 적은 날을 추천한다(B16 변경).
4. **추천은 바로 매거진에 임시 카드로**: 추출이 끝나면 추천 항목은 미리보기를 거치지 않고 바로 매거진 해당 DAY에 "추천" 카드로 뜬다. 카드는 장소 카드와 같은 모양이고 흐리게(투명하게) 보인다. 카드의 "넣기"를 눌러야 저장되고, "고치기"는 저장 전 추천값만 고치고, "빼기"는 추천만 지운다. 원문에 일차·시각이 다 있는 항목만 지금처럼 미리보기를 거친다.
5. **같은 원문 다시 보내기 막음 해제**: B17의 "같은 원문은 실패했을 때만 다시 보낼 수 있다"를 없앤다(F18·F19는 추천을 계속 받는 도우미이므로).

### 하지 않는 것

- 대화로 일정 짜기(F19). 다만 추천 카드 저장소(`suggestions.ts`)와 카드(`suggestion-card.tsx`)는 F19가 그대로 쓸 수 있게 만든다.
- 예약번호 가리기 강화(F20). 담당자 판단으로 기존 일정은 추가 가리기 없이 보낸다(이름·주소에는 기존 `maskPersonal`만 거친다).
- 추천을 DB에 저장하는 것. 추천은 이 브라우저(localStorage, 여행별)에만 둔다. DB 변경 없음.
- 지도 탭에 추천 표시.

## 2. 완료 기준

- [ ] 원문에 날짜·일차·시각이 있는 항목은 그 값 그대로이고 "추천" 표시가 없다.
- [ ] 원문에 일차나 시각이 없는 항목은 미리보기 없이 바로 매거진 DAY에 추천 카드로 뜨고, 입력창에 "추천 N개를 DAY BY DAY에 띄웠습니다" 알림이 보인다.
- [ ] 일차를 전혀 모르는 항목이 무조건 DAY 1로 가지 않는다(AI 추천 → 없으면 일정이 가장 적은 날).
- [ ] 추천 카드는 장소 카드와 같은 모양에 흐리고 점선 테두리·"추천" 표시가 있다. 그 DAY가 펼쳐지고 머리에 "추천 N"이 보인다. 카드를 누르면 시간(추천 표시)·추천 이유가 보인다.
- [ ] 추천 카드 "넣기" → 저장되어 보통 장소 카드(교통·숙소는 GO 줄)로 바뀐다. "고치기" → 저장 없이 추천값만 바뀐다(일차를 바꾸면 그 DAY로 옮겨감). "빼기" → 카드만 사라진다.
- [ ] 새로 고쳐도 추천 카드가 남는다. 공유받은 사람(보기 전용)에게는 보이지 않는다(R-08).
- [ ] 같은 원문을 다시 보낼 수 있다.
- [ ] 메모 종류는 추천 카드로 띄우지 않고 바로 저장되며, 시각을 추천하지 않는다.
- [ ] 기존 R-04(붙여넣기 → 추출 → 미리보기 → 저장)와 개인정보 안내(B18)가 그대로다.
