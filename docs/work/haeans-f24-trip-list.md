  - 목록 화면에서 "여행" 대신 "발자국", 여행 개수 삭제 (안건 6)
  - 새 여행: 이름·목적지·기간 필수, 동행 인원 입력 삭제 (안건 15)

## 2. 완료 기준

- [x] 목록 제목은 "발자국", 아래 문구는 "흩어진 여행 정보를 한 곳에"이고 여행 개수가 보이지 않는다
- [x] 버튼은 "새 발자국", 만들기 창 제목은 "새 발자국", 빈 목록은 "아직 발자국이 없습니다. 새 발자국을 남겨 보세요."
- [x] 만들기 창에 여행 이름·목적지·시작일·종료일만 있고 모두 필수다. 동행 인원 칸이 없다
- [x] 서버(`parseTripForm`)도 목적지·시작일·종료일이 비면 거절한다(화면 검사를 건너뛰어도)
- [x] 카드 미리보기는 DAY마다 첫 관광지(없으면 그날 첫 일정) 하나와, 그날 일정이 더 있으면 가운데 점 "•••". 이름의 괄호 부분은 뺀다. PC 패널은 카드 오른쪽 2/5
- [x] 목적지가 숫자·기호·한글 자음/모음뿐이면 화면과 서버 모두 "목적지는 도시나 나라 이름으로 적어 주세요."로 거절
- [x] 목적지가 Google Places에서 지역(나라·도시 등)으로 확인될 때만 그 영어 이름으로 Unsplash 사진을 넣는다. 아니면 기본 카드
- [x] 내 여행 카드 오른쪽 위에 반투명 ⋯ 버튼 하나. 누르면 대표 이미지 바꾸기·이름 수정·삭제 메뉴. 공유받은 여행에는 없다
- [x] 메뉴: 바깥 누르기·Esc로 닫힘, 열면 첫 항목에 포커스, Esc로 닫으면 ⋯ 버튼에 포커스, 메뉴를 눌러도 여행으로 들어가지 않음
- [x] `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` 통과
