# F13 1화면 종이 형식 삭제

> 상태: 반영 완료(2026-11-04, sync PR #52)

## 1. 범위

- PRD 4절 C8 F13: 1화면 "종이"(B안) 형식을 삭제한다. 크게/종이 전환 버튼을 없애고 PC·모바일 모두 매거진으로 연다.
- C7 "리스트 탭" 후보(F11)의 결론이다(C8 킥오프에서 삭제로 정함).
- 하지 않는 것
  - 매거진 화면 자체의 변경(F16)
  - 공통 문서 수정

## 2. 완료 기준

- [x] 여행 상세에 크게/종이 전환 버튼이 없다.
- [x] PC·모바일 모두 매거진으로 열린다. 예전에 "종이"를 골라 둔 브라우저도 매거진으로 열린다.
- [x] 종이에서만 쓰던 코드(화면, "⋯" 메뉴, 날짜 모양, 형식 고르기)가 남아 있지 않다.
- [x] 매거진·지도 전환과 매거진의 기존 기능은 그대로다.
- [x] `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` 통과

## 4. 결정 (임시 번호)

| 번호 | 영역 | 결정 |
|---|---|---|
| [haeans-f13-remove-paper] 결정 1 | 화면 | 1화면은 매거진 한 형식이다. 형식 전환 버튼과 형식 고르기(브라우저 저장)를 없앤다. D5의 "두 형식", B10(768px 기준 기본 형식·브라우저 저장), B77·B80(종이)을 고친다. B63은 매거진 부분만 남는다. |
| [haeans-f13-remove-paper] 결정 2 | 화면 | 브라우저에 남은 예전 값(`localStorage`의 `stepmap:schedule-format`)은 지우지 않고 읽지도 않는다. 아무 영향이 없어서 지우는 코드를 두지 않는다. |
| [haeans-f13-remove-paper] 결정 3 | 화면 | `ScheduleView`는 지우지 않고 `MagazineView`만 감싸게 둔다. `page.tsx`를 고치지 않아 F16과 충돌을 줄인다. |
